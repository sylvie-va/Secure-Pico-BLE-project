# T10.1: Secure Pico BLE project
A group project for the course ELEC-C7222 Embedded Programming with Communication Devices (Spring 2026 implementation) at Aalto University.

## Description
An implementation of secure Alert Notification Services and Immediate Alert Services via Bluetooth on Raspberry Pi Pico 2 W.
